# 素材与参考绑定

## 默认演示

默认示例由 DemoArtwork.java 直接绘制，没有外部图像、角色 IP 或下载步骤。代码与演示设计随项目采用 MIT 协议。

## 可选图片包

在 app/src/main/assets/wallpaper/ 中放入下列五张 PNG，全部必须为 **1240 × 1754 像素**，保持共同坐标原点，禁止单独裁剪或缩放图层：

| 文件 | 内容 |
| --- | --- |
| original.png | 原始完整画面，睁眼、张嘴状态 |
| body.png | 身体与背景，移除独立头部、头发、手部后补齐所有露出区域 |
| head.png | 头部及头发，真实透明背景 |
| hand.png | 手掌与随之移动的前臂，真实透明背景 |
| expression-closed.png | 同坐标、同大小的闭眼与闭嘴微笑画面 |

五张都不存在时使用程序绘制示例。只放入部分文件会给出明确的开发配置错误，防止混用不匹配图层。图片直接读取本地 assets，不执行任何外部文件或下载。该目录默认被 Git 忽略。

使用素材前确认可修改和再分发；CC0 或包含明确素材授权的 MIT／Apache 示例可作为选择。许可证若只覆盖代码，不能据此推定角色图像也获授权。发布主题应附带素材的原始链接、作者、许可证文本和修改说明。

## 重新标定

目前是固定参考绑定，不会自动识别图中身体。对于其他布局，需要同步修改：

- CharacterMotion：头部、手腕、前臂和身体支点、区域权重。
- HairMotion / SceneMath：饰带／发丝区域、发根、自由末端与面部保护区。
- ShoulderSurface：身体遮挡后发的路径。
- SceneRenderer：前景头发的裁切区域。
- TextureFaceExpressions：左右眼和嘴部矩形、睁眼及闭眼轮廓。

纹理表情图默认采用单位配准矩阵，因此五张图片必须已经对齐。连续眼睑在固定虹膜上移动；闲置时嘴部使用微笑贴图，有效短点按才露出张嘴画面。

## 质量检查

全身与局部都要检查至少一个完整动作周期：发尖不挤压、脸部不拉扯、头发摆开后底层没有残影，皮肤／衣服轮廓连续。提高摆幅后再次检查极值。更换绑定后需要为自己的素材调整图像测试，原引擎的几何单元测试只能覆盖参考布局。
